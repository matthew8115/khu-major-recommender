# 2026학년도 신(편)입생부터 적용되는 졸업요건 변경 안내 (다전공 교육 확대)

> 출처: 2026.10. 공고 / 이미지 자료를 텍스트로 옮김

2026학년도 신·편입생부터 다전공 교육 확대에 따라 졸업요건이 아래와 같이 변경된다.

## 1. 적용 대상
- 가. 2026학년도 신·편입생 (외국인 포함)
- 나. 제외학과 이외 전체 학과
  - ※ 제외학과: 의학계열, 간호학계열, 약학계열(약과학과 제외)

## 2. 변경 내용
- 변경 전: 단일전공으로 졸업 (희망자에 한해 다전공, 부전공, 마이크로디그리 이수 가능)
- **변경 후: 다전공, 부전공, 마이크로디그리 중 택1 필수**

## 3. 다전공 · 부전공 · 마이크로디그리 비교

| 구분 | 다전공 | 부전공 | 마이크로디그리 |
|---|---|---|---|
| 정의 | 본전공(1전공) 외에 타 학과의 전공과정을 지정된 학점 이상 이수하여 2개 이상의 학위를 동시에 취득하는 과정 | 본전공 외에 타 학과의 전공 교과목을 21학점 이상 취득하여 관련 지식을 보완하는 과정 | 사회에서 요구하는 특정 역량개발을 위한 최소 단위의 특화된 교육과정으로, 보통 9학점에서 12학점까지 과정으로 설계됨 |
| 학위 인정 | 학위로 인정 | 학위로 인정하지 않음 | 학위로 인정하지 않음 |
| 증명서 | 학위증: **학위명**, 전공명 기재 / 졸업증명서: 전공명 기재 | 학위증: 전공명 기재 / 졸업증명서: 전공명 기재 (모두 부전공임을 명시함) | 학위증과 졸업증명서에 미기재. 마이크로디그리 이수내역서 및 마이크로디그리수료증 발급 |
| 이수 가능 제한 | 최대 2개 | 제한 없음 | 최대 3개 |
| 심사 유무 | 단과대학별 성적, 학업계획서, 면접 등 심사과정 있음 | 심사과정 없음 | 심사과정 없음 (*) |

(*) 의과대학, 약학대학 마이크로디그리의 경우 별도 심사가 진행될 수 있음 (해당 단과대학으로 문의)

## 4. 참고사항
- 가. 신청 기간
  1. 다전공: 1학기 4월 / 2학기 10월
  2. 부전공: 1학기 4월 / 2학기 10월
  3. 마이크로디그리: 1학기 4월 / 2학기 10월
  4. 기타: 상기 일정은 학사일정에 따라 변동될 수 있음 (각 학기별 공지문 참조 필요)
- 나. 신청 방법: 포털(Info21)에서 신청
- 다. 다전공, 부전공, 마이크로디그리 이수 요건은 각 과정별 **주관 단과대학**에 확인 요망
